**Objetivo:** Ouvindo e Jogando deixam de ser listas de texto e viram seções com capa:
artistas do mês com foto, faixas com capa do álbum, jogo em destaque com capa e barra de
gamerscore. As imagens saem de uma rota própria que só aceita ids validados, então o
visitante nunca fala com Spotify ou Microsoft e a rota não vira proxy aberto.

**Regras desta rodada:** teste vermelho antes de cada implementação; nenhum teste faz rede;
nenhum script de cliente novo; só tokens da escala (o portão `no-ad-hoc-values` vale);
nada de URL de terceiro em `src="..."`.

Regras visuais: capas com `bg-surface-elevated` como fundo enquanto carregam (sem salto
de layout: `width`/`height` no `<img>`); hover só muda `border-color` para `primary`,
`duration-(--duration-fast)`; foco visível `outline-primary` como no resto do site; nenhum
gradiente ou sombra nova. Barra de progresso: trilho `bg-surface-elevated`, preenchimento
`bg-primary`, altura `h-1.5` no destaque e `h-1` na grade, `rounded-full`.

Acessibilidade: imagem com texto ao lado usa `alt=""`; todo card clicável é um `<a>` com o
nome visível; a barra é `role="progressbar"` com `aria-valuenow/min/max` e
`aria-label="Progresso em <jogo>"`, e o texto "690 / 1000 G · 69%" fica visível.

## Lote 1: dados e rota

### Task 1: ids e caminhos de capa

**REQ:** REQ-023, REQ-024 · **Files:** Create `src/lib/now/cover.ts`; Test `tests/now/cover.test.ts`
**Team:** backend · `backend-engineer` (typescript-backend, security-guardrails) · reviewers security-reviewer, test-reviewer

Funções puras:
- `coverPathFromUpstream(url: string): string | undefined` — URL do Spotify (`https://i.scdn.co/image/<40hex>`) vira `/api/now/cover/spotify/<hex>`; URL da Microsoft (`http(s)://store-images.s-microsoft.com/image/<id>`, `id` no padrão `^apps\.\d+\.\d+\.[0-9a-f-]{36}\.[0-9a-f-]{36}$`) vira `/api/now/cover/xbox/<id>`; qualquer outra coisa, `undefined`.
- `upstreamFromCover(source: string, id: string): string | undefined` — o inverso, **montando** a URL a partir do padrão: `spotify` → `https://i.scdn.co/image/<id>`; `xbox` → `https://store-images.s-microsoft.com/image/<id>?w=320&h=320&q=80&format=jpg`. Fonte ou id fora do padrão → `undefined`.

**Step 1 (Red):**

```ts
import { describe, expect, it } from 'vitest';
import { coverPathFromUpstream, upstreamFromCover } from '../../src/lib/now/cover';

const HEX = 'ab67616d00001e02' + 'a'.repeat(24);
const XBOX = 'apps.46694.68182501197884443.ac728a87-7bc1-4a0d-8bc6-0123456789ab.0f1e2d3c-4b5a-6978-8796-a5b4c3d2e1f0';

describe('cover paths', () => {
  it('maps a Spotify image to the local route and back', () => {
    expect(coverPathFromUpstream(`https://i.scdn.co/image/${HEX}`)).toBe(`/api/now/cover/spotify/${HEX}`);
    expect(upstreamFromCover('spotify', HEX)).toBe(`https://i.scdn.co/image/${HEX}`);
  });

  it('maps an Xbox store image, http or https, and asks for a 320 px JPEG', () => {
    expect(coverPathFromUpstream(`http://store-images.s-microsoft.com/image/${XBOX}`)).toBe(`/api/now/cover/xbox/${XBOX}`);
    expect(upstreamFromCover('xbox', XBOX)).toBe(
      `https://store-images.s-microsoft.com/image/${XBOX}?w=320&h=320&q=80&format=jpg`,
    );
  });

  it('refuses anything outside the two patterns', () => {
    for (const url of [
      'https://evil.example/image/x',
      `https://i.scdn.co/image/${HEX}/../x`,
      `https://i.scdn.co.evil.io/image/${HEX}`,
      'javascript:alert(1)',
    ]) {
      expect(coverPathFromUpstream(url), url).toBeUndefined();
    }
    expect(upstreamFromCover('spotify', 'not-hex')).toBeUndefined();
    expect(upstreamFromCover('xbox', '../../etc/passwd')).toBeUndefined();
    expect(upstreamFromCover('github', HEX)).toBeUndefined();
  });
});
```

### Task 2: rota `/api/now/cover/[source]/[id]`

**REQ:** REQ-023, REQ-024 · **Files:** Create `src/lib/now/cover-response.ts`, `src/pages/api/now/cover/[source]/[id].ts`; Test `tests/now/cover-response.test.ts`
**Team:** backend · `backend-engineer` (typescript-backend, security-guardrails) · reviewers security-reviewer, performance-guardrails, test-reviewer

- `serveCover({ source, id, fetch })` em `cover-response.ts` (puro, `fetch` injetado); a rota é casca: `export const prerender = false; export const GET: APIRoute = ({ params }) => serveCover({ source: params.source ?? '', id: params.id ?? '', fetch })`.
- Fluxo: `upstreamFromCover` → `undefined` responde **404 sem chamar fetch**. Senão `fetch(upstream, { redirect: 'error', signal: AbortSignal.timeout(2500) })`. Responde 404 se: status não 200, `content-type` não começa com `image/jpeg`, `image/png` ou `image/webp`, `content-length` acima de 524288, ou o corpo lido passar de 524288 bytes (ler com limite, não confiar só no header). Erro de rede ou timeout: 404.
- Sucesso: 200 com o corpo, o `content-type` da origem, `cache-control: public, max-age=86400, s-maxage=604800, immutable`, `x-content-type-options: nosniff`. Nenhum outro header da origem é repassado (nada de `set-cookie`).
- 404 sempre com corpo vazio e `cache-control: public, max-age=300`.

**Testes:** id inválido → 404 e `fetch` não chamado; origem 200 `image/jpeg` → 200 com os dois headers; origem `text/html` → 404; `content-length: 600000` → 404; corpo de 600 KB sem `content-length` → 404; origem 404 → 404; `fetch` rejeitando → 404; resposta nunca tem `set-cookie` mesmo quando a origem manda.
