# Plano: i18n-sales

> **Spec:** docs/specs/i18n-sales/SPEC.md

**Objetivo:** landing de vendas em inglês em `contrate.nandomoreira.dev/en` e nas seis páginas de serviço `/en/<slug-en>`, com formulário, OG e `hreflang`.
**Arquitetura:** a copy e o catálogo ganham a versão inglesa, validada pelo mesmo schema Zod. O roteamento do subdomínio (`src/lib/sales/host.ts`) aprende o prefixo `/en`, que reescreve para o caminho interno `/en/services[/<slug-en>]`. Os componentes de vendas recebem `locale`, e o handler do formulário volta para a página inglesa pelo `origem`.
**Stack:** Astro 7.2 SSR, Zod 4, Vitest.
**Total de tarefas:** 11.
**Complexidade estimada:** large.
**Depende de:** `i18n-foundation` (locale, dicionário, `ptLeftovers`, `EN_PUBLISHED`, `LanguageSwitch`, `contactOriginOf` no handler, `/en/search.json` da tarefa 14b).

```ts
import type { Locale } from '../i18n/locale';

/** pt-BR service slug -> English slug (i18n-sales S2). */
export const SALES_SLUGS_EN: Readonly<Record<string, string>> = {
  'site-institucional': 'website',
  'landing-page': 'landing-page',
  blog: 'blog',
  'loja-virtual': 'online-store',
  'produto-web': 'web-product',
  'automacao-ia': 'ai-automation',
};

const PT_BY_EN = Object.fromEntries(Object.entries(SALES_SLUGS_EN).map(([pt, en]) => [en, pt]));

/** A service slug in `locale`, from a slug in either language. */
export const salesSlugIn = (slug: string, locale: Locale): string | undefined => {
  if (locale === 'en') return SALES_SLUGS_EN[slug] ?? (PT_BY_EN[slug] ? slug : undefined);
  return PT_BY_EN[slug] ?? (SALES_SLUGS_EN[slug] ? slug : undefined);
};
```
