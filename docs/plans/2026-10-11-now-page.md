# Plano: Página Agora (`/now`)

> **Spec:** `docs/specs/now-page/SPEC.md`
> **Slug:** `now-page` · **Criado:** 2026-10-11
> **Profundidade:** Deep (19 requisitos) · **Tarefas:** 14 em 4 lotes · commit por tarefa

**Objetivo:** página `/now` ("Agora") renderizada no servidor a cada requisição, com Foco
curado, projetos ativos do GitHub, posts e rascunhos, faixas recentes do Spotify e jogos da
OpenXBL, sem JS de cliente novo, sem que uma API fora do ar derrube a página.

**Arquitetura:** `src/lib/now/` concentra tudo. Cada fonte externa é um módulo com um
parser puro (JSON → itens) e um fetcher que recebe `fetch` e o relógio injetados. Um cache
em memória por fonte (`createCachedSource`) dá TTL e serve o último valor bom quando a
renovação falha. `loadNow` junta as fontes com `Promise.allSettled` e devolve um estado por
seção (`ok` | `fallback` | `empty`). A página `src/pages/now.astro` e o builder
`nowMarkdown` são cascas sobre esse estado. Dados curados ficam em `src/lib/now/now.ts`,
no molde de `src/lib/setup/setup.ts`.

**Stack:** Astro 7 SSR, Zod (validação dos payloads externos), Vitest +
`experimental_AstroContainer`.

**Step 3 (Green):**

```ts
export interface CachedSourceOptions<T> {
  ttlMs: number;
  load: () => Promise<T>;
  now?: () => number;
}

/**
 * Per-instance memory cache for one external source. A failed refresh keeps
 * serving the last good value (REQ-012); only a source that never answered
 * rejects, which the caller turns into a fallback section.
 */
export const createCachedSource = <T>({ ttlMs, load, now = Date.now }: CachedSourceOptions<T>) => {
  let value: { data: T; at: number } | undefined;
  let inflight: Promise<T> | undefined;

  return async (): Promise<T> => {
    if (value && now() - value.at < ttlMs) return value.data;
    inflight ??= load()
      .then((data) => {
        value = { data, at: now() };
        return data;
      })
      .catch((error: unknown) => {
        if (value) return value.data;
        throw error;
      })
      .finally(() => {
        inflight = undefined;
      });
    return inflight;
  };
};
```

```ts
export const SOURCE_TIMEOUT_MS = 2500;

export class SourceError extends Error {
  constructor(
    readonly reason: 'timeout' | 'status' | 'network' | 'shape',
    readonly status?: number,
  ) {
    super(status ? `${reason} ${status}` : reason);
  }
}

export const fetchJson = async (
  fetchImpl: typeof fetch,
  url: string,
  init: RequestInit = {},
  timeoutMs = SOURCE_TIMEOUT_MS,
): Promise<unknown> => {
  let response: Response;
  try {
    response = await fetchImpl(url, { ...init, signal: AbortSignal.timeout(timeoutMs) });
  } catch (error) {
    const name = (error as { name?: string }).name;
    throw new SourceError(name === 'TimeoutError' || name === 'AbortError' ? 'timeout' : 'network');
  }
  if (!response.ok) throw new SourceError('status', response.status);
  return response.json();
};

/** One line per failure, never the token, the key or the body (REQ-013). */
export const logSourceError = (
  source: string,
  error: unknown,
  logger: Pick<Console, 'warn'> = console,
): void => {
  const detail =
    error instanceof SourceError
      ? error.status ? `status ${error.status}` : error.reason
      : 'unexpected error';
  logger.warn(`now: ${source} unavailable (${detail})`);
};
```
