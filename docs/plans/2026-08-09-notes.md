# Plan: Notas

> **Spec:** `docs/specs/notes/SPEC.md`

**Goal:** Publicar notas curtas sob `/notas`, sem nenhuma data visível, no mesmo padrão de linha das demais listagens, descobertas pelas rotas de máquina que já existem.
**Architecture:** Uma collection `notes` com schema Zod e o mesmo loader de slug único usado por `projects`. O acesso passa pelo barril de `src/lib/content/`, sob o portão de fonte única. A data existe no frontmatter apenas como metadado de ordenação, RSS e `lastmod`, e um portão dedicado reprova qualquer vazamento dela para o HTML.
**Tech Stack:** Astro 7.2.0, Zod 4, Tailwind 4, TypeScript 5, Vitest.
**Total Tasks:** 11
**Estimated Complexity:** large (9+ tasks)

import { noteSchema } from '../../src/content/schemas/note';

const valid = {
  slug: 'por-que-parenteses-no-tailwind',
  title: 'Por que parênteses e não colchetes no Tailwind 4',
  summary: 'A sintaxe de colchete gera CSS inválido que o browser descarta em silêncio.',

  });

    expect(noteSchema.safeParse(incomplete).success).toBe(false);

    if (result.success) expect(result.data.draft).toBe(false);
  });

  it('accepts optional subject markers', () => {
    expect(noteSchema.safeParse({ ...valid, markers: ['Tailwind'] }).success).toBe(true);
  });

  it('rejects an empty marker', () => {
    expect(noteSchema.safeParse({ ...valid, markers: [''] }).success).toBe(false);

**Step 3: Write minimal implementation**

`src/content/schemas/note.ts`:
```ts
import { z } from 'zod';

export const noteSchema = z.object({
  slug: z
    .string()
    .min(1)
    .regex(/^[a-z0-9]+(-[a-z0-9]+)*$/, 'slug must be kebab-case'),
  title: z.string().min(1),
  summary: z.string().min(1),
  /**
   * Never rendered on a human surface (REQ-002). It exists so notes have a
   * stable order, and so RSS has a pubDate and the sitemap a lastmod.
   */
  date: z
    .string()
    .regex(/^\d{4}-\d{2}-\d{2}$/, 'date must be an ISO-8601 date (YYYY-MM-DD)'),
  markers: z.array(z.string().min(1)).optional(),
  draft: z.boolean().default(false),
});

export type Note = z.infer<typeof noteSchema>;
```
