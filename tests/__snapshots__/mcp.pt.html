~/mcp

Este site fala com Agentes de IA

Adicione este portfólio como conector e o seu agente lê o meu perfil, os cases e o currículo, e confere a minha disponibilidade. Sem conta, sem chave e sem cadastro.

Endpoint MCP

https://nandomoreira.dev/api/mcp

Streamable HTTP, protocolo 2025-11-25, só leitura.

Como conectar

  1. 01

    Claude Code

    No terminal, adicione o servidor:

    claude mcp add --transport http nandomoreira https://nandomoreira.dev/api/mcp

    Depois pergunte: o que o Fernando já colocou em produção?

  2. 02

    Claude

    Em Configurações, Conectores, adicione um conector personalizado e cole o endereço:

    https://nandomoreira.dev/api/mcp

    Conecte e peça para ele avaliar os cases.

  3. 03

    ChatGPT

    Em Configurações, Apps e conectores, ative o modo desenvolvedor e crie um conector com o endereço:

    https://nandomoreira.dev/api/mcp

    Peça para ele chamar get_resume ou check_availability.

  4. 04

    Qualquer cliente MCP

    Cadastre um servidor Streamable HTTP com o endereço:

    https://nandomoreira.dev/api/mcp

    Rode tools/list para ver as 5 tools.

O que o agente pode consultar

  • get_profileQuem eu sou: título, bio, posicionamento, stack, frentes de trabalho e disponibilidade.
  • check_availabilitySe estou aberto a trabalho novo, com o detalhe e a data da última atualização.
  • list_projectsOs cases publicados, com filtro opcional por coleção: portfolio ou lab.
  • get_projectUm case completo: o problema, as decisões, o resultado e os links que o comprovam.
  • get_resumeO currículo completo no padrão JSON Resume, o mesmo de /api/resume.json.

Para propor um projeto

As tools são só de leitura. Para mandar um briefing, o agente faz um POST /api/hire, descrito no guia para agentes. O resumo do site para modelos está em llms.txt.
